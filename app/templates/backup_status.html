Recovery design

MetroCRM creates one encrypted backup package per cycle, then fans that same package out to Local Server, External Drive, Google Drive and OneDrive when configured. A failed destination is recorded as a partial failure without destroying successful copies.

Google Drive and OneDrive OAuth secrets belong in deployment environment variables, never in GitHub or the application database.
