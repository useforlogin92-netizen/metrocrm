Recovery design

MetroCRM creates one encrypted backup package per cycle, then fans that same package out to Local Server, External Drive/PC Agent, Backblaze B2 (S3), Google Drive and OneDrive when configured. A failed destination is recorded without destroying successful copies, and the retry scheduler runs every 10 minutes.

Cloud credentials and OAuth secrets belong in deployment environment variables, never in GitHub or the application database.
