Upload workbook

Only .xlsx files are supported. Maximum file size: 10 MB. The workbook is validated before database changes are committed.

Before importing

  • Keep the column names on the Leads worksheet unchanged.
  • Leave lead_id blank to create a lead; use an existing ID to update one.
  • Check assigned user IDs and customer contact details before upload.
  • Rows are validated as a batch; if a validation error occurs, the import is rolled back.
