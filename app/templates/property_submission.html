1. SM Identity Verification

Before the property is submitted, re-enter the Sales Manager's name and contact number. They must match the details registered for this secure link.

🔐 Identity check: the submitted name and last 10 digits of the contact number are matched against the secure link's registered SM details. This prevents property data from being attributed to the wrong SM.

2. Project / Property Basics

Start with the information that identifies the property.

Open Google Maps ↗
Open Google Maps → find the site → Share → Copy link → paste it here. The link will be available to the CRM team for site visits.

3. RERA & Construction

If a detail is not available, select the appropriate option instead of guessing.

4. Configuration & Inventory

Fill one complete configuration card at a time. Click + Add More below the card to add another configuration; the same BHK can be selected again for another carpet area, rate or price.

Example: 1 BHK → 350 sq.ft → ₹12,000/sq.ft → ₹42,00,000 all-inclusive → Negotiable Yes. Click + Add More and select 1 BHK again for 400.45 sq.ft with its own details, plan chart and optional sample video.

5. Other Pricing & Inventory Notes

Use these optional fields for charges or information that applies to the project generally rather than one configuration.
